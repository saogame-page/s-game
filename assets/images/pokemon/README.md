# assets/images/pokemon/

`games/pokemon-memory`（ポケモン記憶ゲーム）で使うポケモン画像を置く場所です。

- ファイル名は「全国図鑑番号を3桁ゼロ埋めした名前.png」（例：`001.png` `025.png` `151.png`）
- 画像はまだ入っていません。取得手順は
  `games/pokemon-memory/tools/README.md` を参照してください。
- 画像の出典：PokeAPI（https://github.com/PokeAPI/sprites）
