# assets/images/pokemon/

`games/pokemon-memory`（ポケモン記憶ゲーム）と `games/pokemon-quiz`
（ポケモンクイズ）で共用するポケモン画像を置く場所です。

- ファイル名は「全国図鑑番号を3桁ゼロ埋めした名前.png」
  （例：`001.png` `025.png` `151.png` `152.png` `251.png`）
- カントー151匹とジョウト100匹のofficial-artworkをローカル保存して使用します。
- 取得手順は `games/pokemon-memory/tools/README.md` を参照してください。
- 画像の出典：PokeAPI（https://github.com/PokeAPI/sprites）
  ポケモンのキャラクターデザインの著作権は 任天堂／ゲームフリーク／
  クリーチャーズ に帰属します。家庭内・個人利用の範囲でご利用ください。
