# ポケモン画像の取得について

ポケモン記憶ゲーム（`games/pokemon-memory`）で使う画像は、著作権の関係で
このプロジェクトにはあらかじめ含めていません。以下の手順でご自身の
パソコンからダウンロードしてください（家庭内・個人利用を前提としています）。

## 手順

1. パソコンに Node.js をインストールする（未インストールの場合）
   https://nodejs.org/

2. ターミナル（コマンドプロンプト）でこのフォルダに移動する

   ```
   cd s-game/games/pokemon-memory/tools
   ```

3. スクリプトを実行する

   ```
   node download-images.js
   ```

4. `assets/images/pokemon/` フォルダに `001.png` のような画像が
   保存されます（ファイル名は図鑑番号を3桁ゼロ埋めしたもの）。
   ブラウザで `index.html` を開くと画像付きで表示されます。

画像が無い状態でゲームを開いても、エラーにはならず「ポケモン名の
プレースホルダー表示」に自動で切り替わります。急いで画像を用意する
必要はありません。

## 画像の出典・利用範囲

- 取得元：PokeAPI が公開している画像リポジトリ
  https://github.com/PokeAPI/sprites
  （既存の `games/pokemon-quiz` でも同じ取得元を利用しています）
- ポケモンのキャラクターデザインの著作権は
  任天堂／ゲームフリーク／クリーチャーズ に帰属します。
- 本プロジェクトでの利用は家庭内・個人利用の範囲を想定しています。
  商用利用や第三者への再配布はしないでください。

## 今後ポケモンを追加したいとき

1. `games/pokemon-memory/data/pokemon.js` に
   `{ id, name, types, image }` を1件追加する
2. もう一度 `node download-images.js` を実行する
   （すでにある画像はスキップされ、新しく追加した分だけ取得されます）

この手順は、追加するポケモンが数百匹になっても同じです。

## うまく画像が表示されないとき（トラブルシューティング）

`assets/images/pokemon/` の中身が空のままだと、ゲーム画面はすべて
「肉球のプレースホルダー」表示になります（これはエラーではなく、
画像ファイルが見つからない場合の正常な代替表示です）。

1. **まずスクリプトを実行したか確認してください。**
   `node download-images.js` を実行しない限り、画像は自動では
   ダウンロードされません。

2. **実行結果を確認してください。**
   スクリプトは1匹ごとに `取得中:` → `→ 成功` または `→ 失敗` を
   表示します。「失敗」の行があれば、その下に理由
   （`HTTP 404` や `タイムアウト` など）も表示されます。

3. **`assets/images/pokemon/` にファイルが増えているか確認してください。**
   `001.png` のようなファイルが並んでいれば取得成功です。

4. **ブラウザの開発者ツールで確認する場合：**
   `index.html` をブラウザで開き、F12（またはメニューから「検証」）→
   「Network」タブを開いた状態でゲームを進めると、画像リクエストが
   一覧に出ます。該当行が赤字や `net::ERR_FILE_NOT_FOUND` になっていれば、
   その画像ファイルが `assets/images/pokemon/` に無いことが原因です。
   「Console」タブにエラーが出ている場合は、その内容を確認してください。

5. それでも解決しない場合は、`node download-images.js` を実行した際の
   ターミナルの出力（特に「失敗しました」と出た行）をそのまま
   共有してもらえれば、原因を特定できます。
